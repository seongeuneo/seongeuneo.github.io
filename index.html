Claude Code를 활용한 디버깅 자동화 & 성능 개선

새로운 도메인을 맡을 때, 서비스 구조와 주요 로직을 md 파일로 정리해 Claude Code에 학습시킨 뒤 오류 분석을 요청하는 워크플로우를 구축했다. 방대한 로그를 직접 훑는 대신 AI가 원인 후보를 좁혀주며 디버깅 시간을 크게 줄였고, 같은 방식을 성능 개선에도 적용했다.

데이터 저장 2분 → 30초 이내 100~200건 처리 기준

ChatGPT API Fine-tuning — 사주 콘텐츠 기능

jsonl 형식의 데이터셋으로 ChatGPT API를 Fine-tuning해 반려동물 웹앱 내 사주 콘텐츠 기능을 개발했다. 학습 데이터 구성부터 API 연동까지 전 과정을 직접 경험했다.

Claude Code로 인프라 장애 대응 — 배포 서버 디스크 공간 부족

배포 서버의 디스크 공간 부족(AGENT_STORAGE_PRESSURE)으로 배포가 실패하는 장애를 Claude Code와 함께 대응했다. Agent·nginx 서비스를 C→D 드라이브로 이전하는 과정에서 설정 파일·환경변수 곳곳에 C드라이브 경로가 하드코딩되어 발생한 연쇄 장애(에이전트 크래시, 502 에러, nginx 다운타임)를, Claude Code로 로그를 분석하며 "경로 하드코딩"이라는 공통 원인 패턴을 좁혀 하나씩 복구했다.
